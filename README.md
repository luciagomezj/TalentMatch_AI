# TalentMatch AI

TalentMatch AI is a small project I developed using Python and Streamlit to explore how technology can help people find job opportunities that match their skills.

The app allows users to upload their CV in PDF format and automatically identifies skills mentioned in it. It then compares those skills with the requirements of different job positions and shows a matching percentage for each one.

The results are ranked from highest to lowest match, so users can easily see which positions fit their profile best and which skills they might need to develop.

I used Python, Streamlit, Pandas and PyMuPDF to build the application. The job listings are fictional examples, and the matching percentages are based on shared skills rather than actual hiring probabilities.

You can try the app here: [TalentMatch AI](https://talentmatchai-myao9w7qkm7zoq7tqk3kte.streamlit.app)

1. Upload your CV in PDF format.
2. Review the skills automatically detected from your CV.
3. Edit or add skills if necessary.
4. Click "Find my matches" to view recommended positions.
5. Explore matching scores and skills to develop.

## Project Notes

This project is a prototype developed for learning and demonstration purposes. Job listings are sample data, and matching scores represent skill overlap rather than hiring probabilities.

Skill detection and matching are currently rule-based and do not use a generative AI model.
